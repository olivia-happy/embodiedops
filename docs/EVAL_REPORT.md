# SignalForge 离线评估报告

`eval/run_eval.py` 完全离线运行，并把结果写入 `eval/results.json`。它不会启动或调用本地模型，也不会访问远程服务。

## 评估边界

评估包含两组小型、可人工复核的合成回归门槛集；当前尚未完成独立标注者或双人复核：

- `gold_reviews.jsonl`：16 条方面、情绪和证据支持样本，保留原有分类回归指标。
- `gold_decision_memos.jsonl`：7 个决策生成案例，覆盖 `actionable`、分散子问题导致的 `needs_evidence`、弱信号拒绝、反例遗漏、脱敏证据、未知引用失败和模型数字不一致。

决策案例中的 `gold` 是单独编写的预期答案，`prediction` 是固定候选输出，两者分开存储且并不完全相同。`untrusted_model_output` 仅记录应被验证器拦截或修正的示例，不参与最终候选质量计算，而且本脚本不会执行生产验证器。因此，这套评估只能检测指标实现和固定候选结果的退化；验证器安全门槛由后端单元测试覆盖。它不能证明当前本地模型的真实质量，也不能外推到生产流量。

## 决策质量指标定义

| 指标 | 精确定义 | 当前值 |
| --- | --- | ---: |
| `subproblem_evidence_precision` | 逐个统计候选子问题引用的支持证据；子问题名称与预期项相同且证据 ID 位于该预期项支持集合中才计为正确。正确引用数 ÷ 候选支持引用总数；无候选引用时记 0。 | 0.875 |
| `citation_completeness` | 每个案例中，候选 `citation_ids` 覆盖的预期必需支持/反例引用数 ÷ 全部预期必需引用数。它会对遗漏反例扣分。 | 0.929 |
| `unsupported_numeric_rate` | 候选 `numeric_claims` 中，字段不存在于权威 `numeric_facts` 或数值与权威值不一致的声明数 ÷ 候选数值声明总数；无数值声明时记 0。 | 0.000 |
| `decision_status_accuracy` | 在实际产出 memo 的案例中，候选状态与预期状态完全一致的案例数 ÷ 有 memo 的案例数。 | 1.000 |
| `generation_outcome_accuracy` | 候选生成结果（`completed` 并产出 memo，或 `failed` 且不产出 memo）与预期结果一致的案例数 ÷ 全部案例数。未知引用案例按真实生产语义计为 `failed`，不计入 memo 状态准确率分母。 | 1.000 |
| `evidence_plan_specificity` | 只评估预期状态为 `needs_evidence` 的案例。每案四项等权检查：候选子问题覆盖、必采字段覆盖、每个子问题最少证据数不低于预期门槛且至少为 3、复查条件包含预期关键词。通过项 ÷ 可用检查项；没有适用案例时记 0。 | 0.875 |

`unsupported_numeric_rate` 的回归目标为 0。数字不一致案例中，未验证模型草稿故意包含错误数字，最终固定候选只保留权威 facts，因此这一指标验证的是“验证后输出无错误数值”，不是模型本身从未犯错。

## 保留的原有指标

当前 16 条评论样本结果为：方面 macro-F1 `1.000`、情绪 macro-F1 `0.881`、负向证据精度 `0.857`、预测为负向但不支持结论的比例 `0.143`。后两项使用同一组预测负向样本作为分母，分别统计有支持与无支持的比例。人工反馈分布在没有真实反馈时保持全零，避免伪造采用率或满意度。

对当前数据中检索不到证据的问题，生成服务仍必须返回 `INSUFFICIENT_EVIDENCE`，不能生成无来源结论。

## 如何解释结果

这些数值是代码级回归门槛，不是线上实验、独立盲测或生产质量声明。正式质量评估至少还需要：

1. 从目标业务分布中抽样并进行双人独立标注与分歧仲裁。
2. 冻结真实本地模型版本和提示词版本后生成候选，而不是使用固定候选输出。
3. 报告样本量、置信区间、分主题切片、拒绝率和安全失败率。
4. 单独开展行动性人工评分，并追踪实验结果，不能用文本相似度替代业务效果。
