# 项目计划与复盘

## 已完成

- 版本化 DuckDB、演示数据导入、确定性评分和受限生成。
- FastAPI 契约、证据查询、反馈和安全 Trace。
- Next.js 四工作区与空/失败状态。
- 回归门槛集、评估脚本和本地验证脚本。

## 风险与决定

| 决定 | 原因 |
|---|---|
| 默认离线回退 | 演示不依赖模型密钥或网络。 |
| 关键词检索 | 小型本地样本下可解释且可测试。 |
| 人工精选事件 | 避免未经审核的外部抓取与版权风险。 |
| 证据版本约束 | 防止旧版本证据支撑当前结论。 |

## 后续

扩大人工标注评估集；增加可替换的语义检索实现；在不改变证据约束的前提下完善洞察生成的可配置模型提供方。
